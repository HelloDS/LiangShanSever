# 房间记录 CSV 导出

完整编译、严格 TypeScript/Vite 及 215 项 Java 测试已通过，包含真实数据库、私有文件和 worker 组合用例。运行环境 HTTP 五项、真实浏览器创建/下载/撤权，以及已完成文件在 SIGKILL 后新 PID 恢复下载均已通过。原始证据分别见 evidence/room-export-smoke.json、room-export-browser.json、room-export-restart.json；单元/集成用例与实际部署证据分开记录。

导出仅包含与房间列表相同授权范围内的 6003 元数据，不读取手牌、快照、事件载荷、完整回放或玩家联系方式。创建、任务查询及下载分别通过后台接口处理；玩家会话不可使用。后台需要同时具有 game:room:query、game:room:export 和对应平台/圈数据范围。

## 创建和授权

后台“房间记录”选择并查询日期、房号、房主、创建者和状态，再点击“导出当前筛选”，填写用途。服务端复用列表的字段与最多 31 天日期校验，创建任务及业务审计在同一事务完成。Idempotency-Key 的相同请求复用原任务；响应丢失后保留原内容重试，不以生成新任务掩盖未知结果。

任务只能由原创建人按当前权限查询或下载。工作线程不复用旧 JWT 中缓存的权限，而是重新读取若依账号及原有菜单权限逻辑；生成的每个批次、完成标记和下载前还会比较创建时的数据范围摘要。权限撤销、账号停用、范围增加或减少均不能继续读取原文件。这里没有另建一套后台登录系统。

创建使用 READ COMMITTED 事务，容量门锁后的计数能看见前一个创建事务；最多两个未完成任务/人、全服每滚动 24 小时最多 20 个任务。任务历史与业务审计保留，不自动删除数据库历史。

## 工作和恢复边界

单个专用线程及一个未来调度项，每次通过普通数据库池读取最多 200 行并流式写 CSV，不占房间邮箱或房间事务池。数据库门锁与 60 秒租约使同库最多一个有效生成者，续约、完成、失败均带租约令牌；到期最多三次重新领取。旧生成者不能覆盖新的处理结果。筛选损坏会明确失败，不反复阻塞后续任务。

一次最多一万行、8 MiB，生成软预算十分钟；超过上限整体失败，不静默截断成成功文件。发生中断或未知完成时，未确认文件保持私有，任务依靠持久状态和租约恢复。文件先完成再确认数据库 DONE；数据库提交结果未知时不删除可能已经被成功任务引用的文件。

数据以每批实际读取为准；创建时冻结数据库 UTC 时间上界，并按 created_at、永久 room_id 做有界游标推进，避免相同时间的记录被分页跳过。它不是跨全部批次的历史一致性快照；生成过程中状态可能变化，不能当作结算或财务报表。

## 文件与下载

默认目录 .local/exports，可通过 GAME_EXPORTS_DIRECTORY 指定受控私有目录，必须放在静态资源和公共上传映射之外。目录权限 700、文件 600，文件名仅由服务端 UUID 组成；创建、读取拒绝符号链接，不接受请求中的文件路径。下载通过认证接口代理返回，不提供公共静态链接，响应 no-store。

CSV 为带 UTF-8 BOM 的固定十二列：roomId、roomCode、gameId、ownerUid、creatorUid、clubId、status、isTest、roundNo、createdAt、endedAt、ruleVersion。时间明确带 UTC 的 Z。所有单元格加引号并转义双引号；可能被解释为公式的 ASCII/全角前缀、被空白隐藏的前缀和开头的制表/换行使用可见 text: 标记。该标记属于导出文本，程序化导入时需保留或明确处理，不能再将其当成原始未变换字段。

公式风险和表格保存/重开时的差异参考 [OWASP CSV Injection](https://github.com/OWASP/www-community/blob/master/pages/attacks/CSV_Injection.md)。实现对危险文本加上可见标记，不把单纯包引号或单引号前缀当作所有表格软件的普遍保证。

文件到期时间为完成后 24 小时，每次下载重新鉴权并检查到期；每小时只清理受控目录中超过 25 小时、符合服务端命名的文件，保留一小时清理缓冲。不会递归清空目录，也不会删除其他文件。GAME_EXPORTS_ENABLED=false 暂停生成并拒绝新建，既有未过期文件仍按当前授权下载。

任务失败展示稳定分类：权限/范围变化、超过容量、生成未完成、租约恢复次数耗尽或筛选损坏，不输出 SQL、私有载荷、令牌或服务器路径。game.exports.completed / failed / scheduled 指标辅助观察，任务表是权威状态。

## 显式本地验收

RUN_ROOM_EXPORT_FIXTURE=1 node tools/room-export-smoke.mjs prepare 创建明确标记的测试元数据，通过实际 HTTP 创建/重试任务，等待真实 worker 生成并下载。它不代表公开房间建房成功。

checkpoint 会在待终止 Java PID 中再次实际下载并保存摘要；不同 PID 重启后 verify-restart 核对原任务及文件。若关联真实 SIGKILL/137 观察，将明确记录；已完成文件恢复不等于生成中的文件、主机掉电或事务提交 ACK 丢失通过。cleanup 仅移除该条测试房间元数据，任务与审计保留。

RUN_ROOM_BROWSER_FIXTURE=1 node tools/room-browser-fixture.mjs prepare exports 临时启用既有 QA 用户进行浏览器验收；revoke-export 撤回导出权限，cleanup 恢复原菜单、停用账号并撤回临时数据范围。所有凭据只保存在忽略目录，不提交。

本轮真实浏览器发现 743px 宽度下下载列被横向滚动遮住，已固定操作列并重建。459 个 Java 类的摘要前后相同；新构建中下载文件实际为 257 字节、十二列、一条测试记录，且无私有快照。撤回导出权限后的下一次刷新明确报无权限、清空旧行及下载按钮。测试元数据和临时权限已清理，持久任务与审计保留。这里没有执行生成中硬杀、上万行导出或导出与牌局的完整混合容量验收。
