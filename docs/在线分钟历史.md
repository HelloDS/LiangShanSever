# 在线分钟历史

V14 源码、看板曲线、四项真实数据库用例与三项采样用例已通过构建验证，纳入完整 172 项 Java 及严格 TypeScript/Vite 检查。真实分钟 worker 和浏览器验收正在执行。

仅支持方案当前单 Java 进程口径。一个共享调度项在下一分钟边界采集 OnlinePresence.sample() 的真实有效非测试 UID 去重数，保存观察时刻及节点实例。每分钟主键唯一，重启或重复保存保留第一份观察；不会把重启后的零覆盖此前的有效观察。

AVAILABLE 可以为真实零，REBUILDING / UNAVAILABLE 的数量必须为 NULL，数据库约束再次检查。MySQL 写入失败留下空缺和失败指标，不补写伪造的停机在线历史。指标计数表示已确认观察，不代替数据库分钟行数。

后台 GET /game-admin/online/history?date=YYYY-MM-DD 要求看板权限及实时平台范围，每次只查询一个北京自然日、至多 1440 行，SQL/事务限时。列表明确保留 null，时间带 UTC Z；不返回在线 UID 或节点私有信息。曲线不连接缺失/未知分钟点，失败清空旧曲线并明确查询未完成。可选择过去日期并手动刷新，当前日期每分钟更新。

GAME_ONLINE_HISTORY_ENABLED=false 暂停采样并在页面提示，既有历史保留。尚未确定自动清理期限，不添加自动删除。Testcontainers 与内部持久负载明确关闭该后台任务，避免统计采样干扰它们的专用测量。


本地实际分钟 worker 的 HTTP 四项检查通过；浏览器观察真实四个分钟点、测试身份排除与撤权后曲线清空。查询失败明确显示记录数量未知，严格类型/Vite 再次通过，实际重新部署后复核；临时授权已清理。证据 online-history-smoke.json / online-history-browser.json。
