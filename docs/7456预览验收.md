## 修复与回归

- 后端运行时使用内容寻址的只读 JAR 副本，Maven 重打包不再改变运行进程读取的静态资源。实际恢复后台登录 HTTP 200 和游戏重连。
- 客户端允许当前业务服务器的版本化公告 PNG，按来源、路径、尺寸、请求数量约束，恢复公告正文；原有本地资源仍走既有管线。
- 渲染桥只在写入 Cocos 节点名称时将 Egret 数字 ID 转为字符串，保持 Egret 原值；修复亲友圈有数据时“Loading…100%”卡屏。
- Java 补齐旧版亲友圈空房间详情回包与踢出提示字段，非空详情保持关闭。服务明确返回自动开房关闭，客户端据此隐藏相应入口和首次引导。
- 修复过程中完整 Maven 回归通过 218 项；之后补跑空房间协议 4 项和成员字段与权限集成 1 项。最终部署验证真实 WS 的空页、关闭标志、非空请求拒绝及成员字段。客户端公告、运行宿主、渲染桥和 6009 音频专项通过。
- 实际 HTTP/WS 补验 50 项，覆盖玩家筛选及封禁、解禁和下线，公告回滚，传输限制，真实在线历史采样，权限与操作审计，钱包查询及对账，持久任务消费，举报加密。详情在 [证据目录](evidence/preview-7456-20261107/)。
