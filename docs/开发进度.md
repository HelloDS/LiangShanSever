- Flyway MySQL 检测 performance_schema 权限时，Druid 会将探测失败的连接置为不可用。迁移改用 Flyway 自身无池 JDBC 连接，不提高应用数据库权限，不增加第二套连接池；已验证新库迁移成功。
- 本地 MySQL 8.4 的 caching_sha2_password 配合 localhost 明文开发连接，需要 allowPublicKeyRetrieval；该配置仅用于本地配套环境。
- Colima 初始 DNS 软链接指向不存在的目录，已修复本机虚拟机解析。Nginx 按 Upgrade 映射到具名 upstream，避免变量 proxy_pass 触发无 resolver 错误；HTTP 健康及 WS 注册已通过统一 8080 入口。
- 若依密码长度上限为 20；本地初始化密码改为随机 20 字符（120 bit），无固定默认凭据，初始失败尝试已记录并修复。
